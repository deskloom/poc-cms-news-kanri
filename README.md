# 新着情報管理ミニCMS

自社サーバ内で動く想定の、コーポレートサイト用CMSの試作。中心機能として新着情報（お知らせ）の登録・一覧・権限分けだけを作った。

画面は `docs/index.html` をブラウザで開くだけで動く。外部サービスや外部APIは呼ばない。データは架空の8件を画面内に持つ。

## このPOCで確かめたこと

- 新着記事を日付の新しい順に並べ替える
- カテゴリーで絞り込むと該当だけが新しい順で返る
- キーワードで絞り込むと題名に含む記事だけが返る
- 権限により操作可否が変わる（管理者は全部可、編集者は登録・編集のみ、閲覧者は不可）
- 空の題名と本文は登録できない
- 正しい入力は下書きとして登録できる

画面の初期表示（`screens/main.png`・`screens/mobile.png`）では、架空データ8件の一覧とカテゴリー別件数が見える。権限の初期値は編集者で、削除と公開切替のボタンが押せない表示になっている。

## 作っていない範囲

- 問い合わせ管理
- 商品情報の外部連携
- 承認フローや詳細な権限

## 次の進め方

- 下書きから公開までの承認手順を足す
- 問い合わせ管理の一覧を追加する
- 保存先をサーバ内のDBに変える

## 動かし方

1. `npm install`
2. `npm test`（全テストが通る）
3. `docs/index.html` をブラウザで開く
